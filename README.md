# Kubernetes Rollouts Operator

A Kubernetes operator built with Go and Operator SDK for managing Argo Rollouts installations and lifecycle.

## Features

- Automated deployment management
- Progressive delivery support
- Kubernetes native controller
- Custom Resource Definitions (CRDs)
- Operator SDK based architecture

## Technology Stack

- Go
- Kubernetes
- Operator SDK
- Docker
- Argo Rollouts# k8s-rollout-manager
